# demo-ems-logger-rs

This repository is a Rust firmware implementation for the [New Horizons Demo EMS Logger](https://docs.2to8.cc/ems-hardware/demo-ems-logger/) (also known internally as the "Stationary Logger").  The logger implements the Data Logger, or "Level 1" for vaccine cold chain monitoring, as specified by **WHO/PQS/E006/DL01** as part of the [WHO PQS Equipment Monitoring System (EMS) set of specifications](https://extranet.who.int/prequal/immunization-devices/performance-specifications).

It is presently a work in progress; contributions are welcome.
